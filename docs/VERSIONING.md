# Versioning

Settings shows the release version and build number, with a channel label for
prereleases. For example, `1.1.0 beta (5)` is beta build 5 of version 1.1.0.
The number in parentheses identifies the individual build. Stable versions omit
the channel label, for example `1.1.0 (45)`.

Beta releases have not yet completed actual-call verification. Their tags include the channel and
build number, for example `v1.1.0-beta.5`. Stable release tags use the form
`v1.1.0`.
